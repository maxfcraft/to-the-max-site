02 / The rules

How a Lab guide is written

Sources first. Every fact comes from the maker's own pages: help center articles, release notes and official documentation. Each guide links its sources at the bottom, so you can check any line yourself.

Dated, then corrected. Every guide shows the date its sources were last read. When the tool changes, the guide is corrected and the date moves.

Conflicts shown, not smoothed over. When an announcement and the help documentation disagree, the guide quotes both and tells you which one to act on.

No pretend testing. No invented screenshots, results or reviews. If nobody here has used the tool yet, the guide says so on its first screen.
